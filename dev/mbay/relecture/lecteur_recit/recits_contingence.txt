### Cas J : germination (oui/non) selon le traitement des graines, 3 traitements, 30 graines chacun
> m.bay(germe ~ traitement, data = d)

1) Plan reconnu : un facteur, traitement, à 3 groupes (temoin, froid, chaud) ; N = 90.
	--> Réponse catégorielle (2 modalités : non, oui). Une seule question : les proportions diffèrent-elles selon traitement ? Pendant du test du khi-deux.
2) Contrôles des données.
	==> Effectifs par groupe et modalité (3 groupes x 2 modalités) : temoin 12/18 ; froid 12/18 ; chaud 6/24 (non/oui).
	--> Aucune approximation : le calcul est exact, les petits effectifs ne le faussent pas, ils le rendent seulement moins tranché (contrairement au khi-deux, qui demande des effectifs attendus de 5).
3) Loi des données.
	==> Chaque groupe a ses propres proportions des 2 modalités (loi binomiale) ; « aucune différence » : les mêmes proportions dans tous les groupes. Il n'y a pas de forme du bruit à comparer.
4) Point de départ (a priori), fixé avant de voir les données.
	==> 50 % de chances qu'une différence existe (pile ou face : la méthode ne prend pas parti) ; dans chaque groupe, toutes les proportions sont également possibles d'avance (Dirichlet uniforme, Gunel et Dickey 1974).
	--> Ces valeurs ne sont pas ajustées sur les données ; l'étape 5 les fait varier pour voir si la réponse tient.
5) Facteur de Bayes et sensibilité aux a priori. [contingencyTableBF() {BayesFactor}]
	==> Facteur de Bayes, différence contre absence : 0,463.
	==> Précision : calcul en forme close, sans tirage ; aucune erreur de simulation.
	==> Sensibilité : concentration de l'a priori de 0,5 à 2, croisée avec des chances de départ d'une différence de 1 contre 2 à 2 contre 1. La réponse en tête va alors de 42,2 % à 89,4 %.
	--> Prudence ajoutée : la réponse peut s'inverser selon le point de départ ; elle sera dite non tranchée.
6) Quels groupes diffèrent, et de combien. [Dirichlet-multinomial groupings {KefiR}, Dirichlet posterior, hdi() {bayestestR}]
	==> Regroupements les plus probables (5 comparés) : temoin = froid = chaud (58,9 %) ; temoin = froid < chaud (22,3 %) ; temoin < froid < chaud (6,8 %).
	==> temoin et froid : différents à 18,8 % ; écart estimé froid - temoin = 0,0017 [-0,24 ; 0,22], soit 0,0068 [-1,1 ; 0,91] en log du rapport de cotes.
	==> temoin et chaud : différents à 35,1 % ; écart estimé chaud - temoin = 0,19 [-0,025 ; 0,4], soit 0,91 [-0,19 ; 2] en log du rapport de cotes.
	==> froid et chaud : différents à 35,1 % ; écart estimé chaud - froid = 0,19 [-0,037 ; 0,4], soit 0,92 [-0,11 ; 2,2] en log du rapport de cotes.
	Écart estimé : différence des proportions de oui (médiane a posteriori), puis le log du rapport de cotes. Crochets : intervalle de crédibilité à 95 % (la valeur s'y trouve avec 95 % de probabilité ; ce n'est pas un intervalle de confiance).
	--> Toutes les paires viennent d'une seule loi sur les regroupements : aucune correction paire par paire n'est nécessaire, et les réponses ne peuvent pas se contredire.
7) Conclusion : les hypothèses classées, ce sur quoi chacune repose, son soutien.
	Verdict : indécis. Les données ne permettent de conclure ni à une différence, ni à son absence.
	Probabilité de chaque hypothèse, compte tenu des données et du point de départ :
	  1. Les proportions de germe ne diffèrent pas selon traitement : 68,4 % (non tranché)
	  2. Les proportions de germe diffèrent selon traitement : 31,6 %
	     Repose sur les effectifs : ils sont 2,16 fois plus probables si les proportions sont les mêmes que si elles diffèrent.
	  Selon le point de départ, la première réponse va de 42,2 % à 89,4 % : l'ordre peut s'inverser.
	Quels groupes diffèrent par leurs proportions (probabilité, puis écart estimé de la proportion de oui, log du rapport de cotes, intervalles de crédibilité à 95 %) :
	  temoin / froid : semblables, soutien modéré (différents à 18,8 %) ; écart estimé froid - temoin = 0,0017 [-0,24 ; 0,22], delta = 0,0068 [-1,1 ; 0,91].
	  temoin / chaud : semblables, soutien faible (différents à 35,1 %) ; écart estimé chaud - temoin = 0,19 [-0,025 ; 0,4], delta = 0,91 [-0,19 ; 2].
	  froid / chaud : semblables, soutien faible (différents à 35,1 %) ; écart estimé chaud - froid = 0,19 [-0,037 ; 0,4], delta = 0,92 [-0,11 ; 2,2].
	  Regroupement le plus probable : temoin = froid = chaud (58,9 %).
	Proportions observées par groupe (description de l'échantillon) :
	  temoin : non 40,0 %, oui 60,0 % (n = 30)
	  froid : non 40,0 %, oui 60,0 % (n = 30)
