### Cas A : dosage selon le laboratoire, variances inegales (3 labos, 15 dosages chacun, ecarts-types 1, 1, 3)
> m.bay(dosage ~ labo, data = d)

1) Plan reconnu : un facteur, labo, à 3 groupes (L1, L2, L3) ; N = 45.
	--> Une seule question : y a-t-il une différence de dosage selon labo ? Aucun test préalable ne choisit la méthode : les formes du bruit seront comparées, pas choisies.
2) Contrôles des données.
	==> Effectifs : 15 par groupe (3 groupes, N = 45).
	==> Ex-aequo : aucun.
	==> Valeurs éloignées de leur groupe : 2 sur 45 au-delà de 1,5 écart interquartile, 0 au-delà de 3. [Tukey, quantile() {stats}]
	--> Aucune valeur n'est retirée : les 4 formes du bruit restent en lice, et celles à queues lourdes sont là pour ce genre de valeurs.
3) Point de départ (a priori), fixé avant de voir les données.
	==> 50,0 % de chances qu'une différence existe (pile ou face : la méthode ne prend pas parti) ; taille attendue r = 0,5 (échelle « medium » de Rouder et al. 2012) ; chacune des 4 formes du bruit part à 25,0 %.
	==> Avec plus de 2 groupes, deux formes de différence partent à égalité : tous les groupes peuvent différer, ou un seul groupe s'écarte.
	--> Ces valeurs ne sont pas ajustées sur les données ; l'étape 5 les fait varier pour voir si la réponse tient.
4) Comparaison des formes du bruit (la façon dont les valeurs s'écartent du centre de leur groupe : normale ou à queues lourdes, variances égales ou non). [m.bay() {KefiR}, échantillonnage d'importance]
	==> Probabilités a posteriori : queues lourdes, variances inégales 65,3 % ; normale, variances inégales 34,1 % ; queues lourdes, variances égales 0,5 % ; normale, variances égales < 0,1 %.
	==> Variances inégales probables (99,5 %) : le groupe L3 est le plus dispersé (écart-type L3 2,82 contre L2 0,767).
	--> Aucune variance commune n'est imposée : chaque groupe garde sa dispersion dans la comparaison.
	--> Les queues lourdes sont les plus probables (65,9 %), pas assez pour ne parler que des centres (la méthode demande 95,0 % de probabilité) : la réponse mêle moyennes et centres (centre : la valeur typique d'un groupe, proche de sa médiane).
	--> Aucune forme n'est choisie : la réponse de chacune est pondérée par sa probabilité.
5) Facteur de Bayes et précision numérique. [m.bay() {KefiR}]
	==> Facteur de Bayes, différence contre absence : 10^4 (les données favorisent une différence).
	==> Imprécision du calcul par simulation : environ 1,5 % sur le facteur de Bayes, sans effet sur la conclusion (ce n'est pas un risque d'erreur).
	==> Sensibilité : taille attendue r de 0,25 à 1, chances de départ d'une différence de 1 contre 2 à 2 contre 1, répartition des variances entre groupes. « dosage diffère selon labo » va alors de > 99,9 % à > 99,9 %. [m.bay() {KefiR}]
	--> La réponse ne dépend pas de ces choix.
6) Quels groupes diffèrent, et de combien. [lmBF(), posterior() {BayesFactor}, hdi() {bayestestR}]
	==> Regroupements les plus probables (5 comparés) : L1 = L3 < L2 (62,0 %) ; L1 < L3 < L2 (24,8 %) ; L1 = L3 = L2 (7,8 %).

	==> L1 et L3 : différents à 30,2 % ; écart estimé L3 - L1 = 0,39 [-0,8 ; 1,6], soit 0,22 [-0,4 ; 0,92] écart-type.

	Écart estimé : médiane a posteriori, légèrement ramenée vers zéro par l'a priori, donc un peu plus petite que l'écart observé de l'étape 7. Crochets : intervalle de crédibilité à 95 %, si une différence existe (la valeur s'y trouve avec 95 % de probabilité ; ce n'est pas un intervalle de confiance).
	--> Toutes les paires viennent d'une seule loi sur les regroupements : aucune correction paire par paire n'est nécessaire, et les réponses ne peuvent pas se contredire.
	--> Ces paires supposent un bruit normal à variance commune, ce que l'étape 4 n'a pas trouvé : les lire avec réserve.

	Verdict : une différence existe très probablement. Cela ne dit ni qu'elle est importante, ni pourquoi ; les paires sont plus bas.

	  1. dosage diffère selon labo              : > 99,9 % (soutien très fort)
	     Repose sur l'ensemble des écarts entre groupes, le plus grand entre médianes, proches des centres comparés (observé : L2 - L1 = 2,3 ; écart des moyennes 2,2) : les données sont 10^4 fois plus probables avec une différence que sans.
