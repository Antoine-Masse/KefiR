	  • Pas d'effets report [influence sur l'ordre des mesures]

5) ASSOMPTION 3/3 : Contrôle ACADÉMIQUE de l'homogénéité de la variance des groupes.
	Test de Levene [car::leveneTest()] - Variance homogène (homoscédasticité).
	p-value : 0.07.
	Note : Le test de Levene peut avoir été faussé par une asymétrie des données ou des outliers.
	--> L'homogénéité de la variance invite à un contrôle plus tolérant de la normalité.
6) Contrôle plus tolérant de la normalité en cas d'homoscédasticité :
	Contrôle de la normalité des résidus avec tolérance si n>15.

	b) Diagnostic d'influence (distance de Cook) :
		==> 4 observations influentes détectées.
		(8.9% dépassent seuil 4/n = 0.0889).
	c) Normalité diagnostique par groupe :
		Contrôle de la normalité avec tolérance variable selon la taille des groupes.

============ m.bay ============
m.bay(note ~ recette, data = d) 

1) Plan reconnu : un facteur, recette, à 3 groupes (R1, R2, R3) ; N = 45.
	--> Une question : les valeurs de note diffèrent-elles selon recette ?
	Note : valeurs ordonnées : seul compte leur ordre (modèle ordinal).
2) Contrôles des données - valeurs gardées comme catégories ordonnées.
	--> Changement de stratégie : échelle de notation bornée (5 valeurs, de
	    1 à 5) : modèle ordinal au lieu des lois continues.
	==> Effectifs : 15 par groupe (N = 45).
	--> Aucune valeur retirée.
3) Loi des données [polr() {MASS}] - cotes proportionnelles (logit cumulatif).
	==> Seul compte l'ordre des valeurs, pas leurs écarts.
	==> Cotes proportionnelles plausibles (99,8 %, contre un modèle où
	    chaque niveau a ses propres effets).
4) Point de départ (a priori) - 50,0 % de chances d'une différence.
	==> A priori sur les effets : le poids d'une seule observation
	    (information unitaire).
	Note : ces valeurs ne sont pas ajustées sur les données ; l'étape 5 les
	       fait varier.
5) Solidité de la réponse - facteur de Bayes 166, l'ordre ne change pas.
	==> Facteur de Bayes : 166.
	==> Précision : forme close, sans tirage.
	==> Sensibilité : la réponse en tête va de 98,8 % à 99,7 %.
	--> L'ordre ne change pas.
	Note : les chances de départ vont de 1 contre 2 à 2 contre 1.
6) Quels groupes diffèrent, et de combien [polr() {MASS}] - R1 = R2 < R3 en tête
   (58,5 %).
	==> Si une différence existe, regroupements en tête : R1 = R2 < R3
	    (58,5 %) ; R1 < R2 < R3 (35,0 %) ; R1 < R2 = R3 (6,5 %).
	==> R1/R2 : différents à 41,2 % ; R2/R1 = 3,14 [0,80 ; 12,31].
	==> R1/R3 : différents à 99,1 % ; R3/R1 = 21,13 [4,50 ; 99,15].
	==> R2/R3 : différents à 92,8 % ; R3/R2 = 6,72 [1,57 ; 28,84].
	Note : rapport des cotes cumulées, au-delà de 1 pour des valeurs plus
	       hautes dans le second groupe ; [ ; ] = intervalle à 95 % ;
	       1 = pas de différence.
	Note : toutes les paires sont jugées ensemble, sans correction à la
	       Tukey, et ne peuvent pas se contredire.

7) Bilan - note diffère selon recette : 99,4 % (soutien très fort).
	==> Verdict : une différence existe très probablement.
	==> Probabilité de chaque hypothèse :
	    1. note diffère selon recette : 99,4 % (soutien très fort)
	    2. Aucune différence de note selon recette : 0,6 %
	==> Selon le point de départ : 98,8 % à 99,7 % ; l'ordre ne change pas.
	Note : les données sont 166 fois plus probables sous l'hypothèse 1 que
	       sous la 2 (facteur de Bayes ; 1 à 3 faible, 3 à 20 modéré, 20 à
	       150 fort, au-delà très fort).

	==> Différents : R1/R3 (fort) ; R2/R3 (modéré).
	==> Non tranchés : R1/R2.
	==> Si une différence existe, regroupement le plus probable :
	    R1 = R2 < R3 (58,5 %).
	Note : différents à partir de 75 % de probabilité, semblables jusqu'à
	       25 %, sinon non tranchés ; écarts chiffrés à l'étape 6.

	==> Médianes observées : R1 = 2,0 ; R2 = 3,0 ; R3 = 4,0 (moyennes 2,5 ;
	    3,1 ; 4,1).
	Note : pour un compte rendu : « note diffère selon recette (probabilité
	       a posteriori 99,4 %), facteur de Bayes 166 (m.bay {KefiR}, cotes
	       proportionnelles, MASS::polr, approximation BIC). »
	Note : probabilités d'hypothèses, pas des p-values ; ni l'importance, ni
	       la cause d'une différence ; la méthode avec print(resultat,
