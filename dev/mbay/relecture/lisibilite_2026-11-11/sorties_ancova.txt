============ m.test ============
m.test(poids ~ regime + poids0, data = d) 

1) Structure du modèle : ANCOVA classique (pas d'interaction facteur×covariable)
	Pentes parallèles assumées (homogénéité des pentes de régression)
		Facteurs : regime
		Covariables : poids0
	==> Vérifications complètes des assomptions (5 assomptions).
2) ASSOMPTION 1/5 : Indépendance des observations
	C'est une assomption de PLAN qui ne peut pas être testée statistiquement.
	Vérifiez que :
	  • Pas de mesures répétées (chaque observation d'un sujet différent)
	  • Pas d'effets cluster (observations non groupées/emboîtées)
	  • Pas d'effets report (ordre des mesures n'influence pas les résultats)
3) Ajustement du modèle ANCOVA à 1 facteur(s) [lm()]
	Formule : poids ~ regime + poids0
	Contrastes : contr.sum (codage effets pour estimations non biaisées)
	==> Modèle ajusté avec succès (n=30, résidus calculés)
	    Type de Sommes de Carrés sélectionné : Type III [car::Anova(type='III')]
	Note sur l'ordre des termes :
		Le Type III ne dépend pas de l'ordre des termes : ce résultat reste valable tel quel.
	(Facultatif, pour un test séquentiel de Type I : poids ~ poids0 + regime.)
4) DIAGNOSTIC : Test indépendance covariables-facteurs [approche robuste]
	Teste si chaque covariable diffère selon niveaux facteurs
	Méthode : Pour chaque combinaison covariable × facteur :
	  1. Tester normalité covariable par groupes de chaque facteur
	  2. Tester homogénéité variances [var.test() ou bartlett.test()]
	  3. Sélectionner test approprié :
	     • Normal + variances homogènes : ANOVA [aov() sur 1 facteur]
	     • Normal + variances inégales : Welch ANOVA [oneway.test()]
	     • Non-normal : Kruskal-Wallis [kruskal.test()]
	==> Toutes covariables indépendantes des niveaux facteurs (tous p >= 0.05)
	    Assomption d'indépendance des covariables RESPECTÉE
5) DIAGNOSTIC : Influence sur le Modèle [Distance de Cook, Leverage, DFBETAS]
	Détecte observations ayant impact fort sur coefficients de régression (β)
	Seuils : Cook = 0.133 (critique si > 1), Leverage = 0.267
	==> 4 observation(s) dépassent seuil(s) :
	    Leverage seul: 1, DFBETAS seul: 2, Cook + DFBETAS: 1
	    Toutes Cook < 1 (aucune préoccupation critique)
	==> Modèle robuste aux observations individuelles
6) ASSOMPTION 2/5 : Normalité des résidus (contrôle ACADÉMIQUE)
	Sélection du test selon taille échantillon :
	  • n ≤ 50 : Shapiro-Wilk [shapiro.test() {stats}]
	  • 50 < n ≤ 500 : Jarque-Bera [jb.norm.test() {KefiR}]
	  • n > 500 : Skewness/Kurtosis [{KefiR}]
	Test utilisé : [shapiro.test() {stats}]
	Shapiro-Wilk [shapiro.test()]
	==> Les résidus sont normaux (p-value : 0.12).
7) ASSOMPTION 3/5 : Homoscédasticité (contrôle ACADÉMIQUE)
	IMPORTANT : Test sur INTERACTION DES FACTEURS UNIQUEMENT (pas les covariables)
	Justification : Les covariables sont continues => homogénéité testée sur groupes facteurs uniquement
	Test utilisé : [bartlett.test() {stats}] (sélectionné selon résultat normalité)
	  • Résidus normaux : Bartlett [bartlett.test() {stats}]
	  • Résidus non-normaux : Levene [leveneTest() {car}]
		==> Variances homogènes (p >= 0.05).
8) ASSOMPTION 4/5 : Linéarité de la relation Variable Dépendante ~ covariable
	Test : Inclure terme quadratique I(covariable²) et vérifier significativité [lm() avec I(covariable^2)].
	Si terme quadratique significatif => relation non-linéaire.
	  'poids0' : p du terme quadratique = 0.83 (linéaire)
	==> Relations linéaires confirmées
9) ASSOMPTION 5/5 : Homogénéité des pentes de régression
	Test : interaction facteur:covariable doit être NON-significative [lm() + anova()]
	Si significative => pentes de régression différentes entre groupes (violation).
	  regime × poids0: p = 0.77 (homogène)
	==> Pentes homogènes confirmées (droites régression parallèles)

============ m.bay ============
m.bay(poids ~ regime + poids0, data = d) 

1) Plan reconnu : analyse de covariance, regime (3 groupes), covariable(s)
   poids0 ; N = 30.
	--> Question : poids diffère-t-il selon regime une fois poids0 pris en
	    compte ?
2) Contrôles des données [quantile() {stats}] - rien à retirer.
	==> Effectifs : 10 par groupe (N = 30).
	==> Ex-aequo : aucun.
	==> Valeurs éloignées de leur groupe : 3 au-delà de 1,5 écart
	    interquartile, 0 au-delà de 3 (sur 30).
	==> Covariable poids0 : étendue commune 224 à 264, au moins 70,0 % de
	    chaque groupe.
	--> Covariable centrée sur sa moyenne (poids0 = 247) : groupes comparés
	    à cette valeur.
	--> Aucune valeur retirée.
	Note : valeurs éloignées cherchées sur ce que les covariables
	       n'expliquent pas.
3) Forme du bruit - normale à variance commune, seule.
	==> La covariable agit en ligne droite (linéarité non testée).
	--> Aucune valeur éloignée ne met d'emblée la loi normale en doute.
	Note : queues lourdes, variances inégales et courbure ne sont pas encore
	       validées avec des covariables.
4) Point de départ (a priori) - 50,0 % de chances d'une différence.
	==> Taille attendue r = 0,5.
	==> poids0 est dans tous les modèles ; chaque réponse se lit contre les
	    covariables seules.
	Note : ces valeurs ne sont pas ajustées sur les données ; l'étape 5 les
	       fait varier.
5) Solidité de la réponse [lmBF() {BayesFactor}] - facteur de Bayes 44, l'ordre
   ne change pas.
	==> Facteur de Bayes : 44 (les données favorisent une différence).
	==> Précision du calcul : < 0,1 point sur les probabilités, négligeable.
	==> Sensibilité : la réponse en tête va de 93,1 % à 99,0 %.
	--> La réponse ne change pas de côté.
	Note : r va de 0,25 à 1 (rscaleCont avec lui), les chances de départ de
	       1 contre 2 à 2 contre 1.
6) Quels groupes diffèrent, et de combien [lmBF(), posterior() {BayesFactor},
   hdi() {bayestestR}] - R1 < R2 = R3 en tête (62,0 %).
	==> Si une différence existe, regroupements en tête : R1 < R2 = R3
	    (62,0 %) ; R1 < R2 < R3 (33,0 %) ; R1 = R2 < R3 (4,6 %).
	==> R1/R2 : différents à 92,6 % ; R2 - R1 = 8 [2 ; 15], soit 1,09

	==> R1/R3 : différents à 96,7 % ; R3 - R1 = 12 [4 ; 19], soit 1,56
	    écart-type résiduel (covariables prises en compte).
	==> R2/R3 : différents à 36,8 % ; R3 - R2 = 3 [-3 ; 10], soit 0,46
	    écart-type résiduel (covariables prises en compte).
	Note : [ ; ] = intervalle de crédibilité à 95 % (95 % de chances d'y

	Note : l'écart estimé est ramené vers 0 par l'a priori, surtout quand
