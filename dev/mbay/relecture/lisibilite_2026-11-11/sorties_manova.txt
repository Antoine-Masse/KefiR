============ m.bay ============
m.bay(cbind(y1, y2) ~ g, data = d) 

1) Plan reconnu : 2 réponses (y1, y2) comparées ensemble entre les 3 groupes de
   g (A, B, C) ; N = 30 individus.
	--> Une question : les groupes diffèrent-ils sur au moins une des
	    réponses ?
2) Contrôles des données [quantile() {stats}] - rien à retirer.
	==> Effectifs : 10 par groupe.
	==> Valeurs au-delà de 3 écarts interquartiles de leur groupe : y1 0, y2
	    0.
	--> Aucune valeur retirée.
3) Forme du bruit - normale à plusieurs réponses, corrélations prises égales.
	==> Chaque réponse est standardisée ; corrélations entre réponses au
	    sein des groupes : 0,58.
	--> Le modèle prend ces corrélations égales, ce qu'elles sont à peu
	    près.
	Note : des dispersions égales dans les groupes sont supposées, comme
	       dans une MANOVA classique.
4) Point de départ (a priori) - 50,0 % de chances d'une différence.
	==> Deux formes d'une différence, à poids égaux : le même écart sur
	    chaque réponse, ou des écarts qui changent d'une réponse à l'autre ;
	    taille attendue r = 0,5.
	Note : ces valeurs ne sont pas ajustées sur les données ; l'étape 5 les
	       fait varier.
5) Solidité de la réponse [lmBF() {BayesFactor}] - facteur de Bayes 4 400,
   l'ordre ne change pas.
	==> Facteur de Bayes : 4 400.
	==> Précision du calcul : < 0,1 point sur la probabilité.
	==> Sensibilité : la réponse en tête reste > 99,9 % quel que soit le
	    point de départ.
	--> L'ordre ne change pas.
	Note : r va de r/2 à 2r, les chances de départ de 1 contre 2 à 2 contre
	       1.
6) Quelles réponses diffèrent [lmBF() {BayesFactor}] - y1 en tête (> 99,9 %).
	==> y1 : différence entre groupes à > 99,9 % ; moyennes A = 9,5,
	    B = 11,5, C = 13,7.
	==> y2 : différence entre groupes à 99,8 % ; moyennes A = 9,8, B = 11,2,
	    C = 13,0.
	==> Si une différence existe, écarts qui changent d'une réponse à
	    l'autre : 19,1 %.
	Note : chaque réponse lue seule (un facteur, chances égales), pour voir
	       où se trouve la différence ; la réponse globale est celle de
	       l'étape 5.

7) Bilan - Au moins une des réponses (y1, y2) diffère selon g : > 99,9 %
   (soutien très fort).
	==> Verdict : une différence existe très probablement.
	==> Probabilité de chaque hypothèse :
	    1. Au moins une des réponses (y1, y2) diffère selon g : > 99,9 %
	       (soutien très fort)
	    2. Aucune différence de y1, y2 selon g : < 0,1 %
	==> La réponse reste > 99,9 % quel que soit le point de départ.
	Note : les données sont 4 400 fois plus probables sous l'hypothèse 1 que
	       sous la 2 (facteur de Bayes ; 1 à 3 faible, 3 à 20 modéré, 20 à
	       150 fort, au-delà très fort).

	==> Chaque réponse lue seule : y1 > 99,9 % ; y2 99,8 %.

	==> Moyennes observées, y1 : A = 9,5 ; B = 11,5 ; C = 13,7.
	==> Moyennes observées, y2 : A = 9,8 ; B = 11,2 ; C = 13,0.
	Note : pour un compte rendu : « Au moins une des réponses (y1, y2)
	       diffère selon g (probabilité a posteriori > 99,9 %), facteur de
	       Bayes 4 400 (m.bay {KefiR}, BayesFactor, Rouder et al. 2012). »
	Note : probabilités d'hypothèses, pas des p-values ; ni l'importance, ni
	       la cause d'une différence ; la méthode avec print(resultat,
	       detail = TRUE).
