============ m.bay ============
m.bay(y ~ g, data = d) 

1) Plan reconnu : un facteur, g, à 2 groupes (temoin, traite) ; N = 20.
	--> Une question : y diffère-t-il selon g ?
	Note : aucun test préalable ne choisit la méthode ; les formes du bruit
	       sont comparées.
2) Contrôles des données [quantile() {stats}] - rien à retirer.
	==> Effectifs : 10 par groupe (N = 20).
	==> Ex-aequo : 10 % des valeurs répètent une valeur déjà vue.
	==> Valeurs éloignées de leur groupe : 1 au-delà de 1,5 écart
	    interquartile, 0 au-delà de 3 (sur 20).
	--> Aucune valeur retirée : les formes à queues lourdes sont là pour ce
	    genre de valeurs.
3) Formes du bruit [m.bay() {KefiR}] - normale, variances inégales en tête
   (33,7 %).
	==> Probabilités : normale, variances inégales 33,7 % ; normale,
	    variances égales 26,3 % ; queues lourdes, variances égales 21,6 % ;
	    queues lourdes, variances inégales 18,4 %.
	==> Variances : les données penchent vers des variances inégales sans
	    trancher (inégales à 52,1 %).
	--> La réponse porte surtout sur les moyennes (formes normales :
	    60,1 %).
	Note : la forme du bruit est la façon dont les valeurs s'écartent dans
	       leur groupe ; les queues lourdes, des valeurs éloignées plus
	       fréquentes que sous la loi normale.
	Note : aucune forme n'est choisie ; chaque réponse est pondérée par sa
	       probabilité.
4) Point de départ (a priori) - 50,0 % de chances d'une différence (pile ou
   face).
	==> Taille attendue r = 0,5 ; chaque forme du bruit part à 25,0 %.
	Note : ces valeurs ne sont pas ajustées sur les données ; l'étape 5 les
	       fait varier.
5) Solidité de la réponse [m.bay() {KefiR}] - facteur de Bayes 0,821, l'ordre
   peut s'inverser.
	==> Facteur de Bayes : 0,821, soit 1,22 en faveur de l'absence de
	    différence (proche de 1 : les données départagent à peine les deux).
	==> Précision du calcul : environ 1,0 % sur le facteur de Bayes,
	    négligeable.
	==> Sensibilité : « Aucune différence de y selon g » va de 33,7 % à
	    77,8 %.
	--> Prudence ajoutée : l'hypothèse en tête peut s'inverser ; le bilan ne
	    l'affirmera pas.
	Note : le facteur de Bayes dit combien de fois les données sont plus
	       probables avec une différence que sans.
	Note : r va de 0,25 à 1, les chances de départ de 1 contre 2 à 2 contre
	       1, la répartition des variances varie.
6) Quels groupes diffèrent, et de combien [lmBF(), posterior() {BayesFactor},
   hdi() {bayestestR}] - traite - temoin = 0,8 [-0,5 ; 2,2].
	==> Écart estimé traite - temoin = 0,8 [-0,5 ; 2,2], soit 0,49
	    écart-type.
	Note : [ ; ] = intervalle de crédibilité à 95 % (95 % de chances d'y
	       trouver l'écart).
	Note : l'écart estimé est ramené vers 0 par l'a priori, surtout quand
	       les groupes sont petits.

7) Bilan - indécis (Aucune différence de y selon g : 54,9 %).
	==> Verdict : indécis.
	==> Probabilité de chaque hypothèse :
	    1. Aucune différence de y selon g : 54,9 % (non tranché)
	    2. y diffère selon g              : 45,1 %
	--> Selon le point de départ : 33,7 % à 77,8 % ; l'ordre peut
	    s'inverser, non tranché.
	Note : les données sont 1,22 fois plus probables sous l'hypothèse 1 que

	==> Écart estimé traite - temoin : 0,8 [-0,5 ; 2,2] (étape 6).

	==> Moyennes observées : temoin = 12,5 ; traite = 13,6 (n = 10 par

	==> Écarts-types : temoin = 1,1 ; traite = 2,0.
	Note : pour un compte rendu : « Les données ne permettent pas de

	       comparaison de lois du bruit, Rouder et al. 2012. »
	Note : probabilités d'hypothèses, pas des p-values ; la méthode avec
